Plagiarism Detector

#Overview of the Project:
This Python project is a plagiarism detector that compares two essays (as text files), calculates how similar they are and helps detect common words inthe files. It also allows a user to search for a specific word in both essays.

#How does the Project work?
- Reads two essay files from the essay_samples/ folder
- Preprocesses the text by removing punctuation,and  converting the text files to lowercase
- Breaks the text into words
- Compares words to:
  a)Find common words
  b)Calculate plagiarism percentage
  c)Search for specific words in both essays

#How to Run the Program
1. Install python on your computer.
2. Extract the .zip file and open the folder.
3. Check the folder structure, It should look something like this:
        - main.py
        - README.txt
        - essay_samples/essay1.txt
        - essay_samples/essay2.txt
4. Open a terminal or command prompt in that folder.
5. Run this command: "python main.py"
